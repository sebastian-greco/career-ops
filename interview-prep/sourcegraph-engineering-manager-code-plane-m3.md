Strong answer: OOM/monolith decomposition or AI dubbing orchestration. Start with constraints, then isolate root cause, contracts, observability, rollout, and what you would improve.

Strong answer: combine current sabbatical hands-on AI product builds with Riverside architecture review and early full-stack ownership.

### Role-Specific

- **"How would you approach the first month on Code Plane?"** Source: [JD first month](../jds/402-sourcegraph-engineering-manager-code-plane-m3-2026-05-19.md). Best angle: learn direct reports, run the surfaces as a human and agent user, map Product/Design/Solutions feedback, and identify the few highest-leverage bets.
- **"Where do coding agents fail, and how should products be designed around those failures?"** Source: [JD](../jds/402-sourcegraph-engineering-manager-code-plane-m3-2026-05-19.md), [MCP page](https://sourcegraph.com/mcp), [code search at scale blog](https://sourcegraph.com/blog/why-code-search-at-scale-is-essential-when-you-grow-beyond-one-repository). Best angle: workspace context is narrow, confidence can be wrong, deterministic code intelligence matters, and workflows need auditability and review loops.
- **"What would you prioritize across Batch Changes, Executors, MCP, Code Monitors, Code Insights, and src CLI?"** Source: [JD team surfaces](../jds/402-sourcegraph-engineering-manager-code-plane-m3-2026-05-19.md). Best angle: ask for customer/problem context first, then reason around adoption friction, reliability of execution infrastructure, and agent/human shared workflows.
- **"How do you lead a small team of strong ICs as a player-coach?"** Source: [JD Level](../jds/402-sourcegraph-engineering-manager-code-plane-m3-2026-05-19.md). Best angle: use a lightweight operating model: explicit ownership, high technical bar, regular 1:1s, direct feedback, strong review culture, and selective hands-on contribution when it clarifies direction.
- **"How do you use async-first communication well?"** Source: [JD qualifications](../jds/402-sourcegraph-engineering-manager-code-plane-m3-2026-05-19.md), [Sourcegraph values](https://raw.githubusercontent.com/sourcegraph/handbook/main/content/company-info-and-process/values/index.md). Best angle: connect to remote leadership at Riverside, written decision records, structured planning, and transparency without meeting overload.
